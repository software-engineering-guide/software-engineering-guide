Welcome to Software Engineering Guide Discussions

Software Engineering Guide now has GitHub Discussions, a place to ask questions, suggest ideas, and share what you have done with it.

Software Engineering Guide is a guidebook of good practices for software developer teams, including startups, enterprises, and government organizations. It is written for software developer teams, engineering managers, and technical leaders.

## What this means for you

- You can ask questions and get answers from other readers.
- You can suggest topics, fixes, and improvements before anyone writes them.
- You can share how you use the guide.

## Where to go for what

- Questions about using the guide: Q&A
- Suggestions for new or changed topics: Ideas
- Quick community votes: Polls
- Things you have built or tried with the guide: Show and tell
- Everything else: General
- Errors, broken links, or typos: Issues (https://github.com/software-engineering-guide/software-engineering-guide/issues)
